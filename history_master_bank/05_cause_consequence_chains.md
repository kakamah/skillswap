# 05 Cause -> Consequence Chains

Source basis: uploaded markdown extraction of Cambridge International AS Level History: International History, 1870-1945. Page references are only included where the extraction made them reasonably clear. Any OCR damage, internal inconsistency, or weakly supported detail is flagged rather than normalised.


Compact causal chains prioritising chronology, mechanism, and analytical usefulness.

## Imperialism and new powers
- Industrial overproduction + tariff barriers -> search for markets / raw materials -> new imperial expansion after 1870 -> sharper colonial rivalry -> wider tension in international relations.
- Suez route importance -> British intervention in Egypt (1882) -> stronger strategic hold on the route to India -> greater interest in north-east Africa -> stimulus to broader scramble logic.
- Berlin rules on "effective occupation" -> need to prove control on the ground -> faster territorial grabs in Africa -> arbitrary borders + violence -> long-term African instability.
- Shimonoseki -> Triple Intervention -> Japanese resentment + security anxiety -> military expansion -> Russo-Japanese War.
- Boer War costs + concentration-camp scandal -> British military / moral embarrassment -> awareness of isolation and vulnerability -> search for closer diplomatic arrangements -> Entente era.
- German naval and world-policy ambitions -> British alarm -> Entente strengthened -> Germany felt more isolated -> pre-1914 bloc hardening.
- US industrial growth + frontier closure + Mahan-style naval thinking -> desire for overseas bases / markets -> Spanish-American War + Pacific expansion -> USA recognised as a world power.
- US neutrality tested by submarine warfare + Zimmermann Telegram -> US entry into First World War -> Allied victory more likely -> stronger US role in peace-making.

## Peace settlement and 1920s diplomacy
- Allied victory + fear of another German threat -> harsh terms at Versailles -> German resentment + revisionism -> instability built into the interwar order.
- US Senate rejection of League membership -> no US guarantee for France -> deeper French insecurity -> tougher approach to reparations -> Ruhr occupation.
- High reparations + war debts web -> German payment crisis -> Ruhr occupation + passive resistance -> hyperinflation -> Dawes Plan.
- Border-making by self-determination + mixed populations -> minority problems in successor states -> continuing disputes -> League arbitration opportunities and failures.
- Soviet exclusion + German isolation -> Rapallo -> cooperation outside Versailles -> fear among France / eastern states -> proof that excluded powers would revise the system by other means.
- Ruhr failure -> recognition that coercion had backfired -> Dawes Plan -> temporary recovery -> Locarno optimism.
- Locarno western guarantees -> visible diplomatic improvement -> Germany's League entry -> belief in a "spirit of Locarno" -> overconfidence about long-term peace.
- Kellogg-Briand idealism without sanctions -> public rhetoric of peace -> little practical restraint -> large gap between diplomatic language and enforcement capacity.

## China and Japan
- Qing decline + foreign intrusion + weak reform -> 1911 Revolution -> republic without strong institutions -> Yuan's dictatorship -> warlord era.
- Yuan's death -> no accepted central authority -> competing military rulers -> peasant suffering + political fragmentation -> hunger for new ideologies and national reconstruction.
- May Fourth anger over Shantung + wider cultural unrest -> stronger nationalism + political activism -> CCP growth + ideological radicalisation -> sharper KMT / CCP rivalry.
- Soviet support + anti-warlord common interest -> First United Front -> Northern Expedition success -> Nationalist expansion -> Chiang confident enough to purge communists.
- Chiang's anti-communism -> Shanghai Purge / White Terror -> CCP rural retreat -> Jiangxi base -> Long March -> Mao's stronger leadership.
- KMT inability to destroy CCP quickly -> prolonged civil conflict -> both sides weakened before full Japanese invasion -> anti-Japanese strategy became more contested.
- Japanese army autonomy + resource / prestige anxieties -> Mukden Incident -> seizure of Manchuria -> civilian government discredited -> military dictatorship strengthened in Japan.
- League inability to reverse Manchuria -> Japanese confidence rises -> further aggression in China -> wider East Asian war.
- Chiang's priority on communists over immediate war with Japan -> anger among anti-Japanese officers -> Xi'an Incident -> Second United Front.
- Full-scale war with Japan -> KMT retreat inland + heavy civilian suffering -> KMT reputation damaged by corruption and coercion -> CCP expands political support in the countryside.
- US oil embargo -> Japan sees strategic clock running down -> gamble on pre-emptive strike -> Pearl Harbor -> US entry into world war.

## 1930s collapse
- Wall Street Crash -> global depression -> unemployment / social unrest -> extremist politics strengthen -> dictatorships more aggressive.
- Depression + fear of war costs -> Britain and France more cautious -> less willingness to enforce settlements -> aggressors perceive weakness -> further treaty-breaking.
- Manchuria success -> League discredited -> Disarmament Conference atmosphere worsens -> Hitler leaves League -> collective security weakened further.
- Hitler's early successes without forceful response -> Saar + rearmament + Rhineland -> prestige rises -> domestic support rises -> bolder expansion.
- Stresa Front formed -> Anglo-German Naval Agreement undercuts it -> anti-German front weakened -> Mussolini more willing to break with Britain / France -> Axis develops.
- Abyssinia sanctions exclude key materials + Hoare-Laval scandal -> Italy sees League weakness -> Italy leaves League orbit -> closer Rome-Berlin relationship.
- Rhineland remilitarised without resistance -> France strategically weakened + Hitler emboldened -> Anschluss and Sudeten pressure easier.
- Non-intervention in Spain + German / Italian intervention -> fascist states gain confidence and military experience -> democracies look passive -> wider deterrence weakens.
- Munich concessions -> Czechoslovakia weakened -> March 1939 occupation reveals wider German aims -> Britain shifts to Poland guarantee.
- Failure of Anglo-Franco-Soviet talks + Polish distrust of USSR -> no anti-German grand alliance -> Nazi-Soviet Pact -> Poland isolated -> invasion and war.
- Japanese war in China + European crisis in 1939-41 -> separate regional conflicts begin to overlap -> Pearl Harbor + German declaration on USA -> fully global war.
